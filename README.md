# StudyOS Neurology

A standalone Neurology quiz with an Exam 1 question bank, interactive learning guides, and visual study tools.

## Run locally

Download this repository's ZIP, extract it, and open **Neurology.html** in a modern browser. No installation, build step, account, or server is required. The interactive guide opens from the quiz and closes back to your questions; it can also be opened separately as **Neurology_Interactive_Learning_Guide.html**.

## Exam 1

- **229 Focused Exam Review** questions.
- **127 Additional Practice** questions.
- **9 Needs Instructor Review** records retained for transparency but excluded from ordinary graded/random practice.
- **365 total records; 356 eligible** under All Exam 1 Questions.

The quiz includes topic filters, flashcards, explanations, feedback settings, and browser-local progress/history. Keep using the same browser and file location to access the same saved progress. Clearing browser storage may remove it. Exams 2–4 have no content and remain disabled.

## Project files

- `Neurology.html`: self-contained quiz and embedded interactive learning guide.
- `Neurology_Interactive_Learning_Guide.html`: the same guide as a standalone page.
- `review_alignment/final_bank.json`: the final 365-record question-bank export.
- `Neurology_Exam1_Review_Aligned_Question_Bank.md`: readable question-bank export, including held records.
- [Exam 1 coverage notes](docs/Exam-1-Coverage.md): counts, review limitations, and held IDs.

This is an independent StudyOS study aid, not an official Parker University resource or an instructor-provided product. It is for study, not clinical decision-making.
